# Bank-Loan-Report

Hello Everyone,

For those exploring Power BI projects in the finance domain💰, here's something for you! this bank loan analysis project dives deep into data, offering actionable insights to understand loan trends, performance, and risks.📊



🔍Project Highlights:

📊Key Performance Indicators(KPIs)

🔸Total Loan Applications - 38,576

🔸Total Amount Funded - $435.8M

🔸Total Amount Received - $473.1M

🔸Average Interest Rate - 12%

🔸Average Debt-to-Income Ratio(DTI) - 13.3%



📊 Dynamic Filters : Analyze data by

🔰State   🔰Grade   🔰Purpose   🔰Good vs Bad Loan



📊 Charts Used:

◾ Monthly Trends by Issue Date (Line Charts)

◾ Regional Analysis by State (Filled Map)

◾ Loan Term Analysis (Donut Chart)

◾ Employee Length Analysis (Bar Chart)

◾ Loan Purpose Breakdown (Bar Chart)

◾ Home Ownership Analysis (Tree Map)

What I learned ✌

📌Power BI Basics: Worked with BI DAX formulas, dynamic data tables & interactive slicers for deeper analysis.

📌Finance Insights : Learned about loan segmentation, repayment trends and key metrics banks uses to assess performance.


This project wasn't just about creating a dashboard; it was about integrating data analytics with practical business insights to craft a meaningful narrative. While it's not perfect , it marks progress. Every small win contributes to the bigger picture.



For those on a similar learning journey, remember : it's about consistent effort- trying , learning, and improving one step at a time.
